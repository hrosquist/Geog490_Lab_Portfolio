Lab 3: Census Mapping and Visualization

This project explores demographic and economic patterns in King County, Washington using ACS 2020 5-year estimates. The project includes a race/ethnicity dot density map, a graduated symbol map of young persons, and an income choropleth map created in R using ggplot2 and tmap.

Figure 1. Race and Ethnicity Dot Density Map

This map shows selected race and ethnicity groups across King County, Washington using 2020 ACS 5-year estimates. Each dot represents a set number of people.

Figure 2. Young Persons Graduated Symbol Map

Graduated symbols represent the number of people under age 18 by census tract using ACS table B09001.

Figure 3. Median Household Income Choropleth

This choropleth map shows median household income by census tract in King County, Washington using ACS 2020 5-year estimates (table B19013).
