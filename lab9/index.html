Geography of Interest

For this lab, I chose the Seattle-Tacoma-Bellevue MSA using census tracts from King, Pierce, and Snohomish Counties in Washington. This geography is useful for spatial regression because the region contains strong variation in housing values, education, density, age, and neighborhood socioeconomic conditions across urban and suburban areas. The analysis uses 2023 ACS 5 year estimates from the U.S. Census Bureau. Variables were selected to match Walker’s spatial regression example as closely as possible while applying the analysis to a different metropolitan area.

1. Geographically Weighted Regression

I performed a geographically weighted regression (GWR) using median home value as the dependent variable. The explanatory variables included median rooms, percent college educated, percent foreign born, percent white, median age, median structure age, percent owner-occupied housing, population density, and total population. The map below visualizes the local R^2 values from the GWR model using the ColorBrewer YlOrRd color palette.

Figure 1. Geographically Weighted Regression Local R^2 Values

The geographically weighted regression map shows that the model performs differently across the Seattle metropolitan area. Higher local R^2 values indicate neighborhoods where the explanatory variables better predict median home value. Lower values suggest that other factors may influence housing values in those areas. Stronger model performance appears in parts of the urban core and several suburban areas, while weaker relationships occur in outer portions of the metropolitan area. These results show that relationships between socioeconomic characteristics and housing values are spatially uneven across the Seattle region.

2. K-Means Cluster Analysis

I also performed a k-means cluster analysis using the same geography and variables as the GWR model. The clustering analysis grouped census tracts into six clusters based on similar socioeconomic and housing characteristics. A qualitative ColorBrewer palette was used for visualization.

Figure 2. K-Means Cluster Analysis of Seattle Census Tracts

The k-means cluster map groups neighborhoods with similar demographic and housing characteristics across the Seattle metropolitan area. Some clusters are concentrated in dense urban areas, while others are more common in suburban and outer tracts. The map suggests that neighborhoods in the Seattle region can be grouped according to shared patterns of education, housing value, ownership rates, density, and population characteristics. While the clusters simplify complex data into categories, they still highlight meaningful spatial differences across the metropolitan area.

Conclusion

Together, the geographically weighted regression and k-means cluster analyses demonstrate that socioeconomic and housing characteristics vary substantially across the Seattle metropolitan area. The GWR model focuses on local variation in statistical relationships, while the k-means analysis groups neighborhoods with similar overall characteristics. Both methods show that spatial patterns in Seattle are highly uneven and geographically structured.
