Geography of Interest

For this lab, I chose Seattle, Washington, using census tracts in King County as the geography of interest. This area is appropriate because Seattle has strong neighborhood-level variation in income, education, poverty, and employment patterns, making it useful for examining spatial regression and clustering.

The analysis uses ACS 5 year census tract data. The variables include median household income, poverty rate, college attainment rate, and unemployment rate. These variables help describe socioeconomic differences across Seattle-area neighborhoods.

1. Geographically Weighted Regression

I performed a geographically weighted regression using the same general type of socioeconomic variables from Walker’s example, but applied them to the Seattle area instead of the original location. The map below shows how the regression relationship varies spatially across census tracts.

Figure 1. Geographically Weighted Regression Results for Seattle Census Tracts

The geographically weighted regression map shows that the relationship between socioeconomic variables is not constant across Seattle. Some census tracts have stronger local regression values, while others show weaker relationships. This pattern suggests that income, poverty, education, and employment do not affect all neighborhoods in the same way. The variation may reflect differences in housing costs, neighborhood development, access to jobs, and long term patterns of inequality across the Seattle area.

2. K-Means Cluster Analysis

I also performed a k-means cluster analysis using the same Seattle census tract data. The cluster map groups tracts with similar socioeconomic characteristics. I used a different qualitative color palette so the cluster categories are visually distinct.

Figure 2. K-Means Cluster Results for Seattle Census Tracts

The k-means cluster map shows groups of census tracts with similar socioeconomic characteristics. Some clusters appear concentrated near the urban core, while others are more common in outer residential areas. This suggests that Seattle’s neighborhoods can be grouped by shared patterns of income, poverty, education, and unemployment. The clusters do not show exact boundaries between communities, but they help summarize broader spatial differences across the region.

Conclusion

Together, the geographically weighted regression and k-means cluster maps show that socioeconomic patterns in Seattle vary across space. The GWR map focuses on how relationships between variables change locally, while the k-means map groups tracts with similar overall characteristics. Both methods show that Seattle’s census tracts are not socially or economically uniform.
