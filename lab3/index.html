Lab 3: Census Mapping and Visualization

This project explores demographic and economic patterns in King County, Washington using R, tidycensus, sf, ggplot2, and tmap. The maps include choropleth, dot density, and graduated symbol visualizations.

Figure 1. Median Household Income Choropleth

This choropleth map shows median household income by census tract in King County, Washington using ACS 2020 5-year estimates.

Figure 2. Total Population Choropleth

This choropleth map shows total population by census tract in King County, Washington using 2020 Decennial Census data.

Figure 3. Population Dot Density Map

This dot density map shows the distribution of total population across King County, Washington. Each dot represents 100 people.

Figure 4. Young Persons Graduated Symbol Map

This graduated symbol map shows the population under 18 years by census tract using ACS 2020 5-year estimates, table B09001_001.
